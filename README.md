# 🛸 2D Arcade Shooter (Space Invaders-Style)

A 2D arcade shooter developed in Unity, focusing on core gameplay loop implementation and collision mechanics. This project serves as an introductory showcase of game development fundamentals.

## 🎮 Core Mechanics & Features
- **Player Movement:** Omnidirectional spaceship movement with vertical boundary clamping (limited to the bottom half of the screen) and horizontal screen-wrapping (crossing one edge seamlessly teleports the player to the opposite side).
- **Combat System:** Projectile shooting mechanics (Left Click / Spacebar) with real-time hit detection.
- **Enemy Spawning:** Randomized horizontal enemy spawning at the top of the screen with constant downward velocity.
- **Scoring System:** Real-time score tracking UI (+5 points per enemy destroyed).
- **Game State:** Instant game-over state upon player-enemy collision.
- **Art & Assets:** Custom hand-drawn pixel art designed specifically for the Start Screen, seamlessly integrated with academic sprite assets provided by the course professor.

## 🛠️ Technologies & Tools
- **Engine:** Unity 2D
- **Language:** C#
- **Version Control:** Git / GitHub

## 🚧 Current State & Future Scope
This project is currently a prototype demonstrating fundamental mechanics. Future planned updates include:
- Implementation of explosion animations and particle systems.
- UI enhancements (Restart menu, responsive screen scaling/aspect ratio fixes).
- Advanced enemy behavior and progressive difficulty.
